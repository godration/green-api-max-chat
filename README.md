# Тестовое задание: Веб-интерфейс MAX Web (GREEN-API)

Пользовательский интерфейс для отправки и получения текстовых сообщений в мессенджере **MAX** (а также WhatsApp / Telegram) с использованием сервиса **GREEN-API**.

Внешний вид интерфейса спроектирован по прототипу веб-версии [web.max.ru](https://web.max.ru/).

---

## 🚀 Стек технологий

- **React 19**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Lucide React** (иконки)

---

## 📋 Реализованные требования

1. **Вход по учетным данным GREEN-API**:
   - Форма ввода `idInstance` и `apiTokenInstance` (с возможностью кастомного `apiUrl`, по умолчанию `https://api.green-api.com`).
   - Автоматическая проверка состояния инстанса (`getStateInstance`).
   - Сохранение учетных данных в `localStorage`.

2. **Создание нового чата**:
   - Создание диалога по номеру телефона получателя с автоматической валидацией и форматированием в `chatId` вида `{phone}@c.us`.

3. **Отправка текстовых сообщений (Требование №6)**:
   - Метод: `POST {{apiUrl}}/waInstance{{idInstance}}/sendMessage/{{apiTokenInstance}}`
   - Тело запроса: `{ "chatId": "...", "message": "..." }`
   - Поддержка отправки по нажатию клавиши `Enter` (`Shift + Enter` для переноса строки).

4. **Получение сообщений через HTTP API (Требование №7)**:
   - Непрерывный опрос очереди уведомлений:
     1. Вызов метода `ReceiveNotification`:
        `GET {{apiUrl}}/waInstance{{idInstance}}/receiveNotification/{{apiTokenInstance}}?receiveTimeout=5`
     2. Извлечение входящего сообщения при событии `typeWebhook: "incomingMessageReceived"`.
     3. Немедленный вызов метода `DeleteNotification` для очистки очереди:
        `DELETE {{apiUrl}}/waInstance{{idInstance}}/deleteNotification/{{apiTokenInstance}}/{{receiptId}}`

5. **Мониторинг запросов (Live API Monitor)**:
   - Встроенная панель активности с прозрачным логом всех вызовов `SendMessage`, `ReceiveNotification` и `DeleteNotification` (метод, статус, timestamp, JSON payload).

## 🛠 Запуск проекта локально

### Установка зависимостей:
```bash
npm install
```

### Запуск сервера разработки:
```bash
npm run dev
```
Приложение откроется по адресу [http://localhost:3000](http://localhost:3000).

### Сборка для продакшена:
```bash
npm run build
```
Готовая сборка будет находиться в директории `dist/`.

## 🧪 Сценарий проверки для ревьюера

1. Откройте приложение в браузере.
2. В окне авторизации введите `idInstance` и `apiTokenInstance` вашего инстанса GREEN-API (или нажмите кнопку «Заполнить тестовые данные» для ознакомления с интерфейсом).
3. Нажмите кнопку **«Новый чат»**, введите номер телефона получателя (например, `+7 (999) 123-45-67`) и нажмите «Создать чат».
4. Введите текстовое сообщение в поле ввода и отправьте его (нажмите Enter или кнопку со стрелкой).
5. При поступлении ответа от собеседника сообщение появится в окне чата автоматически через HTTP API.
6. Для проверки работы логов откройте панель **«GREEN-API Монитор HTTP»** (иконка пульса в верхней части сайдбара).
